# Mini City Simulator

Браузерный 3D-градостроительный симулятор на React, TypeScript, Vite и Three.js.

## Запуск

```sh
npm ci
npm test
npm run build
npm run preview
```

`npm run e2e` запускает Playwright на установленном Google Chrome (десктоп и эмуляция iPhone 13). Для разработки — `npm run dev`.

## Игровые правила

- Карта 20×20. Дороги должны быть соединены с краем карты; здания требуют соседнюю подключённую дорогу.
- Электростанции с доступом к дорожной сети дают по 80 единиц мощности. Энергия распределяется детерминированно по порядку клеток.
- Налоги, занятость, загрязнение и парки влияют на счастье и миграцию; здания требуют содержания.
- Один шаг симуляции — день. Пауза, скорости 1×/2×/4×, автоматическое или ручное освещение.
- Сохранения локальны; ссылка содержит снимок состояния в URL-фрагменте, без сервера, регистрации и персональных данных. Загрузка ссылки создаёт независимую копию города.
- Кнопки строительства работают с 3D-картой и с координатами для клавиатурного управления.

## Архитектура

- `src/engine.ts`: чистые функции модели, валидация сохранений и формат ссылок.
- `src/CityScene.tsx`: процедурные модели, WebGL, управление камерой, анимация.
- `src/main.tsx`: состояние интерфейса, инструменты строительства, статистика.
- `src/engine.test.ts`, `e2e/game.spec.ts`: автоматические тесты.
- `dist/`: статическая сборка, пригодная для GitHub Pages, Cloudflare Pages или любого HTTPS-хостинга без серверного API.
- `screenshots/`: реальные скриншоты Playwright.

## Ограничения

Модель экономики намеренно агрегированная. Автомобили — визуальная анимация, не индивидуальная транспортная симуляция. Мобильное тестирование выполняется в эмуляции Chrome, не на физическом смартфоне.
